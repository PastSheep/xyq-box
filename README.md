# xyq-box

> 一个"一切皆插件"的独立应用 —— 内核只负责装载能力，能力全部来自插件。

## 一句话定位

**xyq-box** 是一个基于 **TypeScript + Cordis 4** 的独立桌面/Web 应用：
宿主（Host）保持极简，所有功能——面板、主题、命令、数据源、集成——都以**插件**形式存在，
可安装、可卸载、可热重载、可替换实现。

## 核心理念（三条设计纪律）

1. **宿主极简**：宿主壳只做三件事——创建内核上下文、加载默认插件集、渲染 UI 根。
2. **服务即插件**：配置、日志、存储、UI 扩展点……连基础设施都是插件提供的服务，任何服务都可被替换实现。
3. **插件是一等公民**：插件声明依赖（inject）、能力（provide）、权限（permissions）与配置 schema，生命周期由内核统一管理。
